# Acknowledgements

Thank you to the maintainers and contributors of the open-source projects that
help make 42TUI possible.

## Project testers

- [Supra libft tester](https://github.com/nda-cunh/libft_tester) by nda-cunh,
  used for libft.
- [Supra printf tester](https://github.com/nda-cunh/printf_tester) by nda-cunh,
  used for ft_printf through the [42TUI fork](https://github.com/HeduroFR/printf_tester).
- [gnlTester](https://github.com/Tripouille/gnlTester) by Tripouille, used for
  get_next_line through the [42TUI fork](https://github.com/HeduroFR/gnlTester).
- [ft_ps_tester](https://github.com/italoalmeida0/ft_ps_tester) by italoalmeida0,
  used for push_swap.

## Client libraries

- [Textual](https://pypi.org/project/textual/), [Rich](https://pypi.org/project/rich/)
  and [textual-image](https://pypi.org/project/textual-image/) for the terminal UI.
- [Tree-sitter](https://pypi.org/project/tree-sitter/) and
  [tree-sitter-markdown](https://pypi.org/project/tree-sitter-markdown/) for parsing.
- [pyte](https://pypi.org/project/pyte/) for terminal emulation.
- [SQLAlchemy](https://pypi.org/project/SQLAlchemy/) for database access.
- [HTTPX](https://pypi.org/project/httpx/) for HTTP communication.
- [Pillow](https://pypi.org/project/Pillow/) for image processing.
- [keyring](https://pypi.org/project/keyring/) for system credential storage.
- [cryptography](https://pypi.org/project/cryptography/) for cryptographic operations.
