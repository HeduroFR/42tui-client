Install 42TUI

A terminal workspace for École 42 students. Linux and macOS first; native Windows is experimental.

Linux and macOS

curl -fsSL https://tui.42wip.in/install.sh | sh

The installer uses uv and obtains Python 3.12 when a compatible Python is unavailable. System Python stays in place; administrator rights are unnecessary.

To select options, download the script first:

curl -fsSL https://tui.42wip.in/install.sh -o install-42tui.sh
sh install-42tui.sh --font
# Or: sh install-42tui.sh --version 0.2.0 --no-font --non-interactive

Windows (PowerShell)

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://tui.42wip.in/install.ps1 | iex"

Use Windows Terminal. For options, save the script and execute it with PowerShell:

Invoke-WebRequest https://tui.42wip.in/install.ps1 -OutFile install-42tui.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-42tui.ps1 -Font

After installation

Restart your terminal if needed, then run 42tui. Font installation is optional: select JetBrainsMono Nerd Font Mono in your terminal settings. For SSH or WSL, the font belongs on the terminal host.

uv tool upgrade ft-tui
uv tool uninstall ft-tui

Update or uninstall

42tui update
42tui uninstall
# Alias: 42tui remove

These commands use the manager that owns your current installation, without opening the TUI. Source and editable installations should be maintained with their original manager.

To uninstall a production uv installation even when the app cannot start:

curl -fsSL https://tui.42wip.in/uninstall.sh | sh

The uninstaller keeps application data, account credentials, fonts, shell PATH configuration, Python and uv. For pipx installations use pipx uninstall ft-tui.

Uninstall keeps your application data. Existing pipx or development installations require explicit migration; the installer will explain any command conflict.

Installation needs internet access and a writable home directory. Python tooling cannot bypass campus execution policies.
